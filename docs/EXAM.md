# Prüfungssimulation

30 zufällige Fragen aus 111. 60 Minuten regulär; 90/120 Minuten Übungsmodi. Bestanden ab 65 %.

## Punkte
Maximalpunkte = Anzahl richtiger Antworten. Bei drei richtigen Antworten: zwei richtige ohne falsche = 2/3; alle = 3/3; mindestens eine falsche zusätzlich = 0/3; nichts = 0.

Die Gesamt-Maximalpunktzahl variiert mit den gezogenen Fragen. Bitte diese Prüfungslogik im Review bestätigen.
